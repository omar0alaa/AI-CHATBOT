## 🚀 Project Overview
AIChatBot-Python is a professional support chatbot that:
- Answers strictly from a curated knowledge base (SQLite DB)
- Enforces a strict persona (English/Arabic)
- Uses similarity-based retrieval for answers
- Integrates with Ollama for LLM-powered responses
- Provides a modern web-based admin editor for CRUD operations
- Supports session-based chat history
